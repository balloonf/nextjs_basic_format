## 🎯 주요 기능

### ✅ 구현된 권한 시스템
- **역할 기반 접근 제어 (RBAC)**
  - 전역 역할: `user`, `admin`, `super_admin`
  - 조직 역할: `member`, `admin`, `owner`
  - 팀 역할: `member`, `lead`, `admin`

- **조직 기반 접근 제어**
  - 다중 조직 소속 지원
  - 팀별 세분화된 권한 관리
  - 프로젝트 및 리소스 가시성 제어

### 🔐 보안 정책
- **문서 접근 제어**
  - 소유자 권한
  - 공개/비공개/관리자 전용 설정
  - 자동 권한 필터링

- **팀 및 조직 관리**
  - 멤버십 기반 접근 제어
  - 계층적 권한 상속
  - 실시간 권한 검증

## 🛠️ 기술 스택

- **데이터베이스**: PostgreSQL (Supabase)
- **인증**: Supabase Auth
- **보안**: Row Level Security (RLS)
- **클라이언트**: Next.js, React, TypeScript 지원
